ติดตั้งครั้งแรก

ใช้เวลาไม่ถึงนาที ขั้นตอนที่ 3 ทำแค่ครั้งแรกครั้งเดียว

  1. เปิดไฟล์ nowake-1.0.dmg

    ดับเบิลคลิกไฟล์ที่ได้รับมา จะมีหน้าต่างเปิดขึ้นมา ข้างในมี nowake.app, ทางลัดโฟลเดอร์ Applications และคู่มือนี้

  2. ลาก nowake ไปใส่ Applications

    ลากไอคอน nowake ไปวางทับโฟลเดอร์ Applications ในหน้าต่างเดียวกัน เสร็จแล้วกดปุ่มดีดออก (⏏) ที่ดิสก์ nowake ใน Finder ได้เลย

  3. อนุญาตให้เปิดแอป

    ครั้งแรกที่เปิด macOS จะขึ้นว่า “ไม่สามารถเปิด nowake ได้” เพราะแอปไม่ได้เซ็นด้วยบัญชีนักพัฒนาของ Apple ที่ต้องเสียเงินรายปี ไม่ใช่เพราะแอปมีปัญหา ให้กด Done แล้วไปที่

    System Settings›Privacy & Security›Open Anyway

    เลื่อนลงไปจนเจอข้อความเรื่อง nowake กด Open Anyway แล้วใส่รหัสผ่านเครื่องยืนยัน บน macOS รุ่นใหม่ การคลิกขวาแล้วเลือก Open ใช้แทนขั้นตอนนี้ไม่ได้แล้ว

    หรือถ้าถนัด Terminal ใช้คำสั่งเดียวแทนทั้งขั้นตอนได้:

    $ xattr -dr com.apple.quarantine /Applications/nowake.app

  4. หาไอคอนถ้วยกาแฟบนแถบเมนู

    nowake ไม่มีหน้าต่างและไม่ขึ้นใน Dock มันจะอยู่เป็นไอคอนถ้วยกาแฟที่มุมขวาบนของจอ คลิกที่ไอคอนเพื่อเปิดหน้าต่างควบคุม

รหัสผ่าน

ทำไมถึงถามรหัสผ่าน

การสั่งไม่ให้ Mac หลับตอนปิดฝาเป็นการตั้งค่าระดับระบบ ต้องใช้สิทธิ์ผู้ดูแลเครื่อง nowake ใช้คำสั่ง pmset ที่มากับ macOS อยู่แล้ว ไม่ได้ติดตั้งอะไรแปลก ๆ เพิ่มลงในเครื่อง ส่วนคำสั่ง caffeinate ทั่วไปใช้แทนไม่ได้ เพราะมันกันได้แค่เครื่องหลับตอนไม่มีคนใช้ ปิดฝาเมื่อไหร่เครื่องก็หลับอยู่ดี

ตอนเปิดโหมด จะถามรหัสผ่านทุกครั้ง ข้อนี้ปิดไม่ได้ เพราะเป็นการปิดระบบป้องกันของเครื่อง

ตอนปิดโหมด เลือกได้ว่าไม่ต้องถามก็ได้ ถ้าเปิดสวิตช์ Turn off without password แอปจะแสดงให้ดูก่อนว่าจะเขียนบรรทัดนี้หนึ่งบรรทัดลงในไฟล์ /etc/sudoers.d/nowake

ชื่อผู้ใช้ของคุณ ALL=(root) NOPASSWD: /usr/bin/pmset -a disablesleep 0

บรรทัดนี้อนุญาตให้รันได้แค่คำสั่งเดียว คือคำสั่งที่คืนค่าให้เครื่องกลับมาหลับตามปกติ ไม่มีสิทธิ์อื่นเพิ่มเลย และแอปจะให้ visudo ตรวจไฟล์ก่อนติดตั้งทุกครั้ง ถ้าไม่เปิดสวิตช์นี้ ตัวตั้งเวลาและตัวตัดตอนแบตต่ำจะทำได้แค่เด้งหน้าต่างถามรหัสแล้วรอ ซึ่งไม่มีประโยชน์ตอนที่คุณไม่อยู่หน้าเครื่อง

อยากเอาออก ก็ปิดสวิตช์เดิม หรือพิมพ์ใน Terminal:

$ sudo rm /etc/sudoers.d/nowake

อย่าใส่กระเป๋าตอนเปิดโหมดนี้

  • Mac ที่ทำงานอยู่ทั้งที่ปิดฝาระบายความร้อนผ่านคีย์บอร์ดไม่ได้ ถ้าอยู่ในกระเป๋าหรือใต้ผ้าห่ม เครื่องจะร้อนมาก
  • ถ้าใช้แบตอยู่ แบตจะลดลงเรื่อย ๆ ถ้าแบตหมดตอนปิดฝา งานที่ยังไม่ได้เซฟอาจหายได้ ควรตั้ง Turn off below ไว้
  • ปิดโหมดทุกครั้งเมื่อเลิกใช้ การกด Quit ในหน้าต่างควบคุมจะปิดโหมดให้ก่อนออกจากแอป
แก้ปัญหา

คำถามที่เจอบ่อย

เปิดแอปแล้วไม่เห็นไอคอนบนแถบเมนู

แถบเมนูน่าจะเต็ม โดยเฉพาะเครื่องที่มีรอยบากกลางจอ ไอคอนที่ล้นจะไปซ่อนอยู่หลังรอยบาก ลองปิดแอปอื่นบนแถบเมนูสักตัว หรือกด ⌘ ค้างแล้วลากไอคอนอื่นออกเพื่อให้มีที่ว่าง

ปิดแอปไปแล้ว แต่ปิดฝาเครื่องก็ยังไม่หลับ

เกิดได้ถ้าแอปถูกบังคับปิด (Force Quit) หรือเครื่องดับกลางคันตอนโหมดยังเปิดอยู่ ค่าที่ตั้งไว้เลยค้างอยู่ในระบบ วิธีแก้ง่ายสุดคือเปิด nowake แล้วกดปิดสวิตช์ หรือพิมพ์ใน Terminal:

$ sudo pmset -a disablesleep 0

เช็คสถานะได้ด้วยคำสั่งนี้ ถ้าขึ้น No แปลว่าเครื่องกลับมาหลับตามปกติแล้ว

$ ioreg -r -n IOPMrootDomain -d 1 | grep SleepDisabled
      "SleepDisabled" = No
กดเปิดโหมดแล้วไม่มีอะไรเกิดขึ้น

ถ้ากด Cancel ที่หน้าต่างถามรหัสผ่าน แอปจะไม่เปลี่ยนอะไรเลย ลองกดใหม่แล้วใส่รหัสผ่านเครื่อง บัญชีที่ใช้ต้องเป็นบัญชีผู้ดูแลระบบ (Admin) ด้วย

อยากให้เปิดเองตอนเปิดเครื่อง

ไปที่ System Settings › General › Login Items & Extensions กดปุ่ม + ใต้ “Open at Login” แล้วเลือก nowake จาก Applications การเปิดแอปเฉย ๆ ไม่ได้เปิดโหมดให้เอง ต้องกดสวิตช์เองทุกครั้ง

เปิดไฟล์แล้วขึ้นว่าต้องใช้ macOS รุ่นใหม่กว่านี้

nowake ใช้หน้าตาแบบ Liquid Glass ที่มีตั้งแต่ macOS 26 ขึ้นไป เช็ครุ่นได้ที่ เมนู › About This Mac

ลบแอปออกยังไง

กด Quit ในหน้าต่างควบคุมก่อน (แอปจะปิดโหมดให้) แล้วลาก nowake จาก Applications ไปถังขยะ ถ้าเคยเปิดสวิตช์ Turn off without password ไว้ ให้ลบไฟล์นั้นด้วย:

$ sudo rm /etc/sudoers.d/nowake
nowake 1.0 คำสั่งที่ใช้เบื้องหลัง: pmset -a disablesleep
